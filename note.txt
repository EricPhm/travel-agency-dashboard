Overview of Navigation Flow
    1. User visits /dashboard route

    2. clientLoader() runs to check authentication.

    3. If authenticated and admin: show AdminLayout.

    4. AdminLayout renders <NavItems /> inside sidebar (<SidebarComponent>)

    5. User clicks a NavItem → triggers <NavLink to="..." />

    6. React Router changes the URL + renders the page via <Outlet />.
